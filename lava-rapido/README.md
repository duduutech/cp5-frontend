
## O que tem

- Rotas com `createBrowserRouter` + `RouterProvider` + `Outlet` (layout com Header e Footer): `/`, `/agendamentos`, `/sobre`.
- `useContext`: `AgendamentosContext` guarda os tíquetes e o Header mostra quantos carros aguardam.
- Agendamentos: formulário (cliente, modelo, placa, tipo de lavagem), tíquetes com botão de exclusão.
- Estilização somente com Tailwind CSS.
